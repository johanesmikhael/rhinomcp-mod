# Sample files

| file | what it is |
| --- | --- |
| `example.3dm`, `example.gh` | the original RhinoMCP sample scene |
| `material_library.3dm` | materials for the material tools |
| `stair_jointtypes.3dm` | three blocks, each set 100 mm forward |
| `stair_toppling.3dm` | the same stair at 300 mm |
| `pavilion_jointtypes.3dm` | four walls in a pinwheel, roof set on top |
| `bridge_jointtypes.3dm` | 10 m truss on two pads, 47 elements |
| `timber_bridge_xbraced.3dm` | 24 m timber truss on two pads, 104 elements |

Open one and run `mcpmodgraph` to see the connectivity overlay: which elements touch and the
bearing surface each contact was measured over.
